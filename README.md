# Minecraft Bossfight Mods

Game voxel 3D bergaya Minecraft dalam satu file HTML (Three.js).
Fitur: dunia acak 5 pulau bertema (utama, salju, kota kuno, jamur, End),
portal antar pulau, 29 boss di darat, laut & langit (Golem Batu, Boss Mojang,
Golem Merah, Sea Eater, Raja Laba-Laba, Warden, Slime Mata Banyak, Wither,
Spiderman, Ular Raksasa, Ninja, El Gran Maja, Golem Lava, Golem Jamur,
Shadow, Tentakel Laut, The Bloop, Kraken, Ender Dragon, Hiu End,
Matahari Laser, Sea Hand Monster, Ningen, Robot, Kembaran Jahat,
Naga Pelangi, Godzilla, Ghidorah, Witherzilla), boss laut yang mati jika
terdampar di darat, pistol, mode terbang, kontrol PC + mobile.

Dua mode di menu: **MAIN** (boss muncul satu per satu) dan **ALL BOSS**
(seluruh boss muncul bersamaan).

## Deploy ke InsForge (Sites)

Dari folder ini, jalankan:

    npx @insforge/cli login
    npx @insforge/cli deployments deploy .

Setelah selesai, game bisa diakses di https://<appkey>.insforge.site
